# Español MX

Free Mexican Spanish study app (A2 → B2) that installs on an iPhone as a PWA.

- Spec: `PLAN.md` · Agent brief: `CLAUDE.md` · Choices: `DECISIONS.md`
- Dev: `npm install && npm run dev`
- Build: `npm run build` (output in `dist/`, served at `/spanish-app/`)
- Deploy: push to `main`; GitHub Actions publishes to GitHub Pages.
